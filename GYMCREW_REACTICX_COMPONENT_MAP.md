# GymCrew ↔ Reacticx Component Map

Generated by the Phase 0 discovery audit. This is a **planning map**, not a completed migration record — per AGENTS.md §37, nothing here should be read as "already migrated." Update the "Status" column as each component actually moves (Phase 3 onward).

## Real Reacticx catalog (verified via reacticx.com, 2026-09-16)

Reacticx ships **~100 components**, fetched via `npx reacticx add <name>` and copied into the project (default `src/components/ui`, configurable via `component.config.json` from `npx reacticx init`). Required shared native deps: `react-native-reanimated`, `react-native-gesture-handler`, `react-native-svg`, `@shopify/react-native-skia`, `expo-haptics`, `expo-blur`. **Important finding: the catalog skews heavily toward motion/FX and carousel/marquee components, not a full basic form-and-layout design system.** There is no generic `card`, plain `text-input`, `checkbox`-as-such (there is `check-box`), or `list`/`flat-list` component. AGENTS.md's assumption that Reacticx directly supplies buttons/cards/inputs/switches/tabs/sheets/dialogs/accordions/menus/progress/loaders/lists is **only partially true** — see the gap notes per category below.

Categories present: **FX/orbs/gradients** (apple-intelligence, aurora, chroma-ring, energy-orb, grainy-gradient, mesh-gradient, siri-orb, skia-ripple, wave-scrawler, glow, liquid-metal, radial-intro), **text effects** (animated-text, circular-text, curved-marquee, dynamic-text, fade-text, gooey-text, staggered-text, animated-masked-text, dynamic-island, marquee, title), **controls** (animated-scroll-progress, animated-theme-toggle, countdown, elastic-slider, flexi-button, gooey-switch, hamburger, spin-button, stacked-chips, switch, theme-switch, check-box, radiant-button, button, otp-input, picker, segmented-control, seekbar, squiggly-slider, ruler, stepper), **layout/overlay** (accordion, animated-chip-group, animated-header-scrollview, animated-input-bar, avatar, avatar-group, badge, blur-carousel, bottom-sheet, bottom-sheet-stack, dialog, disclosure-group, dropdown, empty-state, flip-card, infinite-menu, matched-geometry, morphing-tab-bar, pagination, parallax-header, split-view, stack-aware-tabs, stack-cards, tabs, curved-bottom-tabs), **carousels** (cinematic, circular, material, parallax, rotate, scale, tilt, vertical-flow, vertical-page), **loaders/progress** (circle-loader, circular-loader, progress, progress-circular, pulsing-dots, shimmer, shimmer-wave, spinner-arc, orbiting-dots), **misc utility** (qr-code, rolling-counter, ripple, ruler, lanyard, toast, dynamic-island, search-bar, scrollable-search), plus 4 full-screen templates (chat, settings, sign-up ×2).

**Gaps vs. what GymCrew needs**: no generic Card, no plain multi-line/labeled TextField (closest: `animated-input-bar`, `otp-input`, `search-bar`), no line/area/bar chart component, no calendar component, no camera component. These will need custom GymCrew-branded builds composed from Reacticx primitives (or kept as existing third-party libs like `react-native-gifted-charts`, `react-native-calendars`, `expo-camera`) per AGENTS.md §35's escalation order.

## Recommended migration order (component layer, Phase 3)

1. `ConfirmModal` → `dialog` (low risk, fixes the documented Alert.alert web bug everywhere it's adopted)
2. `ProgressBar` → `progress` (highest fan-out, low complexity)
3. `Stepper`, `FormField` (canonical input primitives, high reuse)
4. `Skeleton`/`HomeSkeleton` → `shimmer`
5. `AvatarStack` → `avatar-group`
6. `BottomSheet` (highest risk — do this once the team has confidence from 1-5, since ~15+ components depend on it)
7. Everything else, screen-by-screen per the phased plan in `GYMCREW_REACTICX_MIGRATION.md`

Branded/bespoke visuals (`MuscleHeatmap`, `RankBadge`, `DivisionBadge`, `BadgeRevealFx`, etc.) are never "migrated to Reacticx" in the sense of being replaced — they get their surrounding chrome (padding, shadows, pressable states) rebuilt on Reacticx primitives while the branded asset/animation core stays untouched.
